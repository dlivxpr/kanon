# Kanon UI 设计规格

> 本文档是 Kanon（知识库 + 待办 + 项目管理三合一本地优先桌面应用）的权威 UI 与交互设计规格。  
> 视觉与壳体基线基于 `docs/woday.html`，知识库管理与块级富文本编辑器体验吸收自 `docs/yuque.html`。  
> 领域术语严格遵循根目录 `GLOSSARY.md`，关键领域边界决策见 `docs/adr/0001-document-single-kb-ownership.md`、`docs/adr/0002-checklist-vs-linked-task.md` 与 `docs/adr/0003-sqlite-workspace-source-of-truth.md`。  
> 对应可交互高保真原型：`docs/kanon.html`（视觉表现以 `docs/kanon.html` 现行版本为准；业务逻辑与领域规则以本文档、术语表及 ADR 为准）。

---

## 1. 产品定位与设计原则

- **产品定位**：个人本地优先（Local-first single-user）的三合一效率桌面软件。剔除语雀的社区与多人协作 UI（逛逛、点赞、文档评论、协作者邀请、权限锁图标、互联网公开分享、空间/团队），保留个人高频能力（收藏、模板中心、本地历史版本、回收站）。
- **支持平台**：仅 Windows / macOS 桌面端，兼顾窄窗口折叠。先在 Windows 真机验收；通过后再配置 GitHub CI，验收 macOS。
- **界面语言**：简体中文为主。
- **视觉融合法则**：
  - **外框与工作台沿用 Woday**：深炭黑窗口外壳 + 暖白/深灰圆角内容面板 + 柔和胶囊控件 + 克制信息密度 + 默认珊瑚红（`#ff4f4f`）主强调色（设置中支持切换强调色）。
  - **知识库与文档沿用语雀**：书目式知识库首页（统计 + 点线目录）、独立可折叠多级目录树、阅读/编辑两态分离、顶部语雀格式工具条、块级 `/` 斜杠卡片、悬浮大纲短线 rail、左写右流「小记」卡片墙；保存/完成/更新等正向反馈辅以克制语雀绿（`#00b96b`）。
- **首个验收切片与模型分期**：SQLite Schema 与纯 Rust 领域核心按已校对的完整业务逻辑一次性建好；首轮 UI 与 Windows 真机验收仍锁定最小切片——从项目进入关联的知识库文档，把普通清单项显式转成任务，安排到今天，在「今天」完成任务后文档卡片与项目列表显示同一状态且重启后保留（完整日历、小记、模板中心等视图按同一规则分期接入）。
- **编辑器验证**：先在 Windows 上用 NSH 0.6.0 `RichEditor` 验证中文输入、撤销及关联任务卡片联动，再定文档存档格式。遇到原生编辑器能力不足时暂停，由用户决定是否调整交互或技术路线。

## 2. 领域模型与信息架构

### 2.1 核心领域对象关系

完整术语定义见 `GLOSSARY.md`。核心关系如下：

```text
Workspace（本地工作区）
├── Knowledge Base（知识库） 1..n
│   └── Catalog Node（目录节点：纯分组 或 文档节点） 0..n  ── 树状递归
│       └── Document（文档，严格单归属唯一知识库；ADR-0001）
│           ├── Block / Card（块级内容与特色卡片）
│           ├── Checklist Item（普通文档清单项，仅留文档内；ADR-0002）
│           ├── Linked Task Card（关联任务卡片，双向同步全局 Task；ADR-0002）
│           └── Local Snapshot（本地历史快照）
├── Project（项目） 0..n
│   ├── linked_kb / linked_node（可选关联的知识库或目录分组；ADR-0001）
│   ├── Milestone（里程碑） 0..n
│   └── Task（归属该项目的任务） 0..n
├── Task（全局任务：未排期且无项目即位于 Inbox 收件箱） 0..n
│   └── status: todo | in_progress | done | cancelled
├── Quick Note（小记：碎片想法流，支持一键转文档或提取为任务） 0..n
└── Tag（全局标签：跨知识库/文档/项目/任务/小记横向聚合） 0..n
```

### 2.2 全视图多标签页路由表

任何主视图均可作为独立标签页打开，每个标签页维护独立的 `past / future` 前进后退历史栈：

| 路由 / 视图 ID | 标签标题示例 | 图标 | 内层目录侧栏 | 右侧上下文面板默认状态 |
|---|---|---|---|---|
| `start` | 开始 | 仪表盘 | 隐藏 | 按任务类场景记忆 |
| `today`（默认启动页） | 今天 | 太阳 | 隐藏 | 默认展开（`任务速览`） |
| `upcoming` | 即将到来 | 日程 | 隐藏 | 延续任务类场景 |
| `tasks` | 待办 | 复选框 | 隐藏 | 延续任务类场景 |
| `calendar` | 日历 | 日历 | 隐藏 | 延续任务类场景 |
| `quick-notes` | 小记 | 羽毛笔 | 隐藏 | 默认收起 |
| `favorites` | 收藏 | 星标 | 隐藏 | 延续上次状态 |
| `tags` / `tags/:tag` | 标签 / `#设计` | 标签 | 隐藏 | 延续任务类场景 |
| `project/:id` | 项目名（如 `Kanon`） | 项目色标 | 仅在「关联文档」子视图展开 | 延续任务类场景（点击任务切 `任务详情`） |
| `kb` | 全部知识库 | 书架 | 隐藏 | 默认收起 |
| `kb/:bookId` | 知识库名（如 `AI`） | 书本图标 | **展开**（语雀目录树） | 默认收起 |
| `doc/:docId` | 文档标题 | 文档图标 | **展开**（语雀目录树） | 默认收起（露悬浮大纲短线 rail）；展开可看 `大纲 / 关联任务与反链 / AI` |
| `trash` | 回收站 | 回收站 | 隐藏 | 默认收起 |
| `settings` | 设置 | 齿轮 | 隐藏 | 默认收起 |

## 3. 窗口壳体、多标签栏与四栏响应规则

### 3.1 单行窗口顶栏与工作标签

1. **窗口顶栏**（桌面 `56px`）：左侧为窗口控制位、侧栏开关、前进/后退和本地存储状态；中间为工作标签；右侧为搜索、新建、面板模式和右栏开关。搜索只占一个放大镜按钮，点击或按 `Ctrl/⌘+K` 打开搜索与命令面板。
2. **工作标签**：占用顶栏剩余宽度，主画布不再另设标签行。保留图标、标题、固定态、关闭、拖拽重排与 `+` 新建；空间不足时在标签栏内横向滚动。
3. **窄窗**：窗口宽度不超过 `700px` 时，模式组收进「选择面板模式」菜单；搜索、新建与面板开关仍然直接可达。

### 3.2 标签页交互规则

- **新建标签（`+` 或 `Ctrl/⌘+T`）**：打开 `开始` 工作台。
- **单击左侧导航/目录项**：若目标已在某个标签页打开，则直接聚焦该标签页；否则在当前未固定标签页内导航跳转（若当前标签页已固定，则自动新开标签页）。
- **强制新标签**：鼠标中键点击、`Ctrl/⌘ + 单击` 任意导航/文档/项目入口，固定新开标签页。
- **快捷键**：`Ctrl/⌘+W` 关闭当前未固定标签、`Ctrl/⌘+Shift+T` 恢复最近关闭标签、`Ctrl/⌘+Tab` 切换标签、`Ctrl/⌘+1..9` 直达前 9 个标签。
- **分屏边界**：首期不做主画布左右分屏，通过多标签页 + 右侧上下文面板满足对照需求。

### 3.3 双层左侧栏结构

1. **外层：Woday 深色主侧栏（展开 `232px` / 折叠图标轨 `64px`）**
   - **主导航区**（每项可在设置中配置显隐）：`开始`、`今天`（默认启动页）、`即将到来`、`待办`、`日历`、`小记`、`收藏`、`标签`。
   - **可折叠分区：`项目`**（标题右侧 `+` 快速新建项目）：列出活跃项目，显示色点/Emoji + 名称 + 未完成任务计数徽标。
   - **可折叠分区：`知识库`**（标题右侧 `+` 新建知识库、`>` 进入全部知识库总览）：列出常用知识库，显示彩色书本图标 + 名称。
   - **底部固定区**：`回收站`、`设置`（收起态以图标按钮保留）。
2. **内层：语雀知识库目录侧栏（`252px`，可独立收起）**
   - 仅在 `kb/:bookId`、`doc/:docId` 以及项目页「关联文档」子视图下内嵌在圆角主面板左侧。
   - 顶部：书名下拉切换器（快速切换其他知识库）+ 知识库更多菜单（编辑信息/模板/导出/移入回收站）。
   - 工具行：库内快速过滤输入框 + `+` 新建文档/分组下拉按钮。
   - 固定入口：`首页`（书目页）。
   - `目录` 区：标题栏含「定位当前文档」与「全部展开/收起」按钮；下方为多级混合目录树（支持纯分组节点与文档下嵌套子文档、拖拽排序调级、悬停/右键菜单）。排序与展开规则对齐语雀：顶部 `+` 新建插入目录最顶部，在某节点下新建成为其子节点；记住各节点展开/折叠态，首次打开默认仅展开第一层。

### 3.4 四栏防挤压响应式规则

桌面窗口在文档页最多存在 4 列（外层主侧栏 `232px` + 内层目录侧栏 `252px` + 主正文区 + 右侧上下文面板 `300px`），按以下断点自动协调，保证正文阅读宽度不被挤碎：

| 窗口宽度断点 | 外层主侧栏 | 内层目录侧栏 | 右侧上下文面板 | 正文阅读区策略 |
|---|---|---|---|---|
| `>= 1440px` | 保持用户设定（默认展开 `232px`） | 文档/知识库页默认展开 `252px` | 分场景记忆（任务类默认展开收件箱；文档类默认收起露大纲短线） | 文档列宽居中 `max-width: 780px` |
| `960px – 1439px` | 进入含目录侧栏的标签页时**自动收折为 `64px` 图标轨**（仍允许用户手动临时展开） | 保持展开 `252px`，可手动收起 | 同上；若用户手动展开右栏且同时展开目录栏，自动保持外层图标轨 | 留白收缩至 `24px–32px`，正文保持 `>= 560px` |
| `< 960px` | 图标轨（`< 680px` 切左侧滑出抽屉） | 切为主面板内覆盖式抽屉，选完文档自动收起 | 切为右侧覆盖式抽屉浮层 | 主画布占满可用宽 |

## 4. 核心视图详细规格

### 4.1 「开始」工作台（Start）

融合语雀「开始」页与 Woday 每日概览，作为新标签页默认落地页：
- **快捷入口网格（4 列）**：`新建文档`、`新建知识库`、`新建项目`、`模板中心`。
- **今日速览条**：显示今日待办数、进行中项目数与逾期提醒，一键跳转 `今天`。
- **最近文档表**：分段切换（`最近编辑` / `最近浏览` / `已收藏`）+ 知识库筛选下拉；列表展示文档图标、标题、归属知识库路径、更新时间与收藏星标。

### 4.2 待办与轻日程视图（今天 / 即将到来 / 待办 / 日历）

严格继承 `docs/woday.html` 的排版节奏与空间呼吸感，同时纳入四态任务流转（`todo / doing / done / cancel`）与项目归属：
- **今天（Today）**：页头日期 + `今天 / 前一天 / 后一天` 控件 → 横向连续日期选择条（14–18 天）→ 问候统计卡（当日任务数、高优先级数、进行中数）→ 结转入口（把排期早于今天且仍待办或进行中的任务移至今天，清除原排期时分，不改变截止日或截止时分）→ 按所选排期日展示任务列表（已逾期任务在当日列表附带逾期红标；点击左侧圆圈统一在 `done ↔ todo` 间切换，切 `doing / cancel` 通过任务详情或看板；行内元信息显示时间、所属项目色标、关联文档芯片、标签芯片；点击任务标题在右侧上下文面板打开「任务详情」）。
- **即将到来（Upcoming）**：按**排期日**（晚于今天）展示，支持 `列表`（按天分组）与 `看板`（按天分列）双视图切换；任务有截止日时在行内/卡片内附加截止标记。
- **待办（Tasks）**：按互斥优先级 `逾期 > 今天 > 即将到来 > 收件箱 > 未排期（项目内或仅有截止）` 分组（不重复显示，同时命中逾期与今日排期时归入「逾期」并标出今日排期），另列 `已完成 / 已取消`，支持按状态、优先级、项目筛选与排序。
- **日历（Calendar）**：支持 `3 天 / 周 / 月` 视图，默认按**排期日**展示任务，同时展示 **Project Milestone**（以菱形/旗标区分）；若任务仅设截止日未设排期日，则在截止日以截止旗标展示；点击日期可快速新增该日排期任务或跳转详情。
- **时间语义**：排期与截止各自可有时分，按设备当前时区解释；切换时区不改显示的本地日期和时分。截止有时分时按该时间判定逾期，只设截止日时从次日本地零点起逾期。

### 4.3 项目（Project）

每个项目页顶部呈现项目头（图标/色标、名称、简介、进度条、关联知识库快捷入口）与 4 个子视图切换：
1. **概览与里程碑**：项目目标说明、关键指标卡（总任务 / 进行中 / 已完成 / 关联文档数）、里程碑列表（目标日期 + 进度条 + 关联任务折叠清单；删除里程碑只清空所属任务的里程碑引用，不删除任务）。
2. **任务列表**：按状态或里程碑分组的任务列表，顶部支持快速行内新建任务与筛选。
3. **看板（Kanban）**：按任务状态分列——`待办`、`进行中`、`已完成`（可选显示 `已取消` 列）；卡片显示标题、优先级标识、截止日、子任务计数、关联文档徽标；支持拖拽卡片跨列变更状态，点击卡片在右栏打开任务详情。
4. **关联文档**：若项目已关联知识库或目录分组（ADR-0001），直接复用语雀内嵌目录侧栏 + 文档阅读/编辑两态画布；在此页新建文档默认落于关联目录分组下（关联整本知识库时落于知识库根目录顶部）。关联的目录分组进入回收站时，项目保持绑定并提示「关联目录在回收站中（支持一键恢复或改绑）」；该分组永久删除时，项目自动解除绑定回到「未关联」状态（不自动扩大为整本知识库）。未关联时展示明确空态引导（「绑定已有知识库/目录」或「一键创建同名关联知识库」）。

### 4.4 知识库总览、书目首页与文档阅读/编辑两态

1. **知识库总览（`kb`）**：顶栏提供卡片网格/列表切换与 `+ 新建知识库`；上方显示「常用/置顶知识库」，下方按分组列出全部知识库卡片（图标、名称、简介、文档数与字数）。
2. **知识库首页（`kb/:bookId`）**：复刻语雀书目卡片——居中纸面容器（`max-width: 1000px`），头部展示大号书本图标、知识库名称、文档数/总字数、收藏与新建按钮；中部为欢迎语/简介；下方为带虚线点线引导（dot leader）与更新时间的可折叠书目目录。
3. **文档阅读态（`doc/:docId`, `editing = false`）**：
   - 顶栏精简为：内层目录折叠钮（折叠时显示）、文档标题与所属知识库面包屑、右侧操作组（`收藏`、`本地历史版本`、`更多（模板/导出/删除）`、主按钮 **`编辑`**（语雀绿或强调色胶囊，快捷键 `E` / `⌘E`））。
   - 正文居中窄栏（`max-width: 780px`），零编辑工具条干扰，清晰渲染 H1–H4、段落、列表、普通清单（阅读态可勾选普通清单项或关联任务卡片；当该文档正在另一工作标签处于编辑态时，阅读标签同步显示最新正文但锁定普通清单项为只读并提示跳转编辑标签，关联任务卡片仍可直接勾选）、代码块（带语言标签与复制按钮）、LaTeX 数学公式、内嵌表格、高亮提示块（Callout）、折叠块（Toggle）、分割线、图片/附件与行内 `@` 引用芯片。
   - 底部左下角显示字数统计；右侧上下文面板收起时，画布右边缘展示**语雀式悬浮大纲短线 rail**（短线长度按标题层级分级，悬停/点击展开大纲浮层并平滑滚动定位）。
   - 恢复历史版本只恢复标题、正文和引用位置。恢复出的关联任务卡片显示任务当前状态；任务已移除时显示失效卡片，不恢复任务本身。
4. **文档编辑态（`doc/:docId`, `editing = true`）**：
   - 编辑内容持续本地自动保存至正式正文，SQLite 提交成功后才显示「已自动保存」（保存失败时保留当前草稿并提供重试）；同时按静默/时间间隔自动留存历史记录（自动记录），避免长时编辑或异常退出丢失回退点。点击 **「完成」** 退出编辑态；支持随时手动「保存为命名版本」。
   - 同一文档可以在多个工作标签页阅读，但同一时间只允许一个标签编辑。在其他标签点击「编辑」时，切换到当前负责编辑的标签。
   - 正文顶部吸顶展示**语雀风格格式工具条**：绿色圆形 `+` 插入卡片菜单、撤销/重做、标题层级下拉、加粗/斜体/删除线/下划线/行内代码、无序/有序/普通清单、**插入关联任务卡片**、引用、代码块、表格、公式、高亮块、折叠块、清除格式。
   - 块级交互：空行或行中输入 `/` 弹出卡片命令菜单；输入 `@` 插入**行内提及（inline）**（文档 / 任务 / 项目 / 日期），不打断段落并计入目标的反向链接（目标进回收站后显示失效态，恢复即恢复）；支持 Markdown 快捷语法（`# `、`- `、`1. `、`- [ ] `、`> `、```` ``` ````）；选中普通清单项可一键「转为关联任务」并选择目标项目或收件箱（ADR-0002）。
   - 空白新建文档默认直接进入编辑态，并在正文下方展示常用模板快捷卡片（点击一键套用）。

### 4.5 小记（Quick Note）

沿用语雀小记的「左写右流」双栏体验：
- 左侧吸顶便签卡片编辑器（支持叠纸底边视觉、Markdown/清单快捷输入、标签输入框、发布按钮 `Ctrl/⌘+Enter`）。
- 右侧时间流 / 网格瀑布流视图切换 + 实时搜索 + 置顶分组；每条小记卡片悬停或点击菜单支持：`置顶`、`转为知识库文档`（弹出选知识库确认，生成独立文档后**原小记自动归档**，移出默认活跃流但保留可查）、`提取为任务`（生成独立收件箱任务，**原小记保留**）、`删除`。

### 4.6 右侧上下文面板（Right Context Panel）

右栏保留独立圆角面板，宽屏下最宽 `326px`。面板模式在窗口顶栏选择；面板内部从标题和当前操作开始，不再重复一排模式图标。
- **任务速览（Task Overview）**：右栏分别展示逾期、今天、收件箱任务，按互斥优先级 `逾期 > 今天 > 收件箱` 归组（同一任务在右栏不重复出现；顶栏徽标只计收件箱）。收件箱仅包含状态为待办或进行中、且无项目、无排期日、无截止日的任务。速记待办可回车或点「添加任务」；切换「速记小记」后保存到独立小记流并显示最近三条小记，不创建任务、不增加收件箱计数。
- **任务详情（Task Detail）**：在任意视图点击任务后切入，支持编辑标题、状态（待办/进行中/已完成/已取消）、优先级、排期日及可选时分、截止日及可选时分、所属项目、标签、子任务、备注，以及查看/跳转关联文档。
- **迷你日历（Mini Calendar）**：月历小组件，有任务的日期带红点提示，点击日期联动筛选或跳转。
- **文档大纲（Outline）**：文档视图专属，展示完整可点击跳转的 H1–H3 标题树。
- **关联与反链（Links & Tasks）**：文档视图专属，分两节展示「本文档关联的任务卡片（可直接勾选/改状态）」与「引用本文档的反向链接（文档与项目）」。任务进入回收站后，正文卡片保留原位并显示「任务已移除」，不可勾选。恢复任务即恢复卡片；永久删除后保留失效标记。
- **AI 助手（预留槽位）**：保留 Woday 顶部星芒入口与右侧面板空态占位，后续接入本地/自定义 API 模型。

## 6. NSH 动效规范与动效清单（Motion Inventory）

### 6.1 动效 Token

| Token | 时长 | 曲线 / 用途 |
|---|---|---|
| `instant` | `120ms` | `ease-out`：悬停洗色、图标色切换 |
| `fast` | `180ms` | `cubic-bezier(0.22, 1, 0.36, 1)`：按钮按压缩放（`0.97` / 图标钮 `0.95`）、复选框勾选 |
| `base` | `240ms` | `ease-in-out`：导航/标签选中滑移、阅读/编辑按钮切换、浮层退场、侧栏宽度过渡 |
| `slow` | `320ms` | `ease-out`：弹窗/命令面板/模板中心入场（上升 `10pt` + 缩放 `0.97 -> 1`） |

### 6.2 屏幕状态动效清单

| 交互与状态变化 | 动效方案与 Token | NSH 实现工具 | `prefers-reduced-motion` |
|---|---|---|---|
| 按钮 / 导航行 / 目录行悬停 | 透明洗色淡入，`instant` `ease-out`，不改变尺寸 | `transition_color()` | 即时切换 |
| 按钮 / 胶囊按压 | 整体缩放至 `0.97`（图标按钮 `0.95`），`fast` soft settle | `transition_transform()` + `.active()` | 禁用缩放，仅深色洗色 |
| 标签页切换 / 侧栏激活项移动 | 单一激活指示底色/状态过渡，`base` `ease-in-out` | `Animated` `timing` | 即时跳转 |
| 标签页新建与关闭 | 新标签淡入并展开，关闭收缩退场，`fast` | `LayoutAnimation` | 即时增删 |
| 外层主侧栏 / 内层目录栏 / 右侧上下文面板展开与折叠 | 平滑布局过渡，`<1440px` 自动收折时触发一次，`base` | `LayoutAnimation` | 即时切换 |
| 阅读态 ↔ 编辑态切换 | 顶部格式工具条向下展开淡入（`base` `ease-out`）；「编辑」↔「完成」按钮色彩与文案平滑过渡 | `motion().entering(..)` | 即时切换 |
| 悬浮大纲短线 rail → 大纲浮层 | 从右侧滑出 `8pt` + 缩放 `0.97 -> 1` 淡入，`fast` | `Popover` starting/ending style | 即时显隐 |
| 任务勾选完成 / 取消 | 圆圈缩放回弹（`fast`）+ 勾号描边淡入 + 标题淡灰划线 | `spring` / `transition` | 即时切换状态 |
| 看板卡片拖拽跨列 | 拖拽过程 1:1 跟手无缓动；释放后落位回弹，`base` | `spring` + `LayoutAnimation` | 即时落位 |
| 命令面板（`⌘K`）/ 模板中心 / 弹窗 | 遮罩淡入 + 弹窗上浮 `10pt` 与缩放 `0.97 -> 1` 入场（`slow`），退场 `fast` | `Dialog` motion | 即时显隐 |
| Toast 反馈条 | 底部上移 `8pt` 淡入（`fast`），2.2s 后下移淡出 | `motion()` | 即时显隐 |
| 列表首次进入与数据实时刷新 | 页面切入轻淡入（`fast`）；复用列表行与实时打字计数**无动画** | `motion()` | 无动画 |

## 7. 键盘导航与可访问性

- **全局快捷键**：
  - `⌘K` / `Ctrl+K`（兼容 `⌘J` / `Ctrl+J`）：打开全局搜索与命令面板（支持 `>` 命令前缀）。
  - `⌘T` / `Ctrl+T`：新建标签页（打开「开始」）；`⌘W` / `Ctrl+W`：关闭当前未固定标签；`⌘1..9` / `Ctrl+1..9`：切换标签页。
  - `⌘\` / `Ctrl+\`：折叠/展开外层深色主侧栏；`⌘.` / `Ctrl+.`：折叠/展开右侧上下文面板。
  - `E`（文档阅读态非输入焦点时）或 `⌘E` / `Ctrl+E`：在阅读态与编辑态间切换；`Esc`：关闭弹窗/浮层。
- **焦点与语义**：所有交互元素具备清晰的 `:focus-visible` 焦点环（`2px solid accent`）、语义角色（`tablist` / `tab` / `tree` / `treeitem` / `dialog` / `switch` / `checkbox`）与中文 `aria-label`；关键操作不依赖纯悬停触发，均保留键盘或明确菜单入口。
