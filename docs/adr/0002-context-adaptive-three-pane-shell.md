# 采用上下文自适应三栏外壳融合 Woday 与语雀布局

Woday 的核心视觉骨架是「左侧深色导航栏 + 中央暖白主面板 + 右侧独立暖白副面板」三栏，而语雀阅读与编辑文档时需要同时呈现「知识库目录树 + 窄栏正文 + 右侧文档大纲」。为避免在中央白面板内再切分栏导致四至五栏挤压，我们决定保持全屏严格最多三栏：在左侧深色栏内以手风琴单展开方式内联呈现当前激活 `Project` 或 `Book` 的 `Catalog` 目录树，中央主面板专注呈现项目驾驶舱或 760px 文档正文，右侧独立副面板则按上下文在 `Inbox`（收集箱）、`Outline & Links`（文档大纲、关联任务与 `Backlink` 双链）、`Task Detail`（任务详情）、`Mini Calendar` 与 `AI Assistant` 之间多模态切换。
