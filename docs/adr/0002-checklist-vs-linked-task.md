# 文档内普通清单项与全局任务显式分离，仅关联任务卡片双向同步

Kanon 同时具备块级富文本文档和全局待办/项目管理。我们决定文档中直接键入的普通 `- [ ]` 仅为 `Checklist Item`（留在文档内部），不自动注入全局 `Inbox` 或「今天」视图；需要纳入待办与项目追踪的行动项，必须显式转化为 `Task` 或通过 `/`、`@` 嵌入关联任务卡片，由关联任务卡片与全局待办/看板保持双向实时同步。

## Considered Options

- **所有 `- [ ]` 自动同步为全局任务**：文档中的大量检查清单（如发布清单、调研要点）会污染「今天」和收件箱，破坏待办列表信噪比。
- **文档与任务完全独立**：文档里的行动项无法进入项目看板与排期流，失去三合一协同价值。

## Consequences

- 编辑器需要区分「普通清单块」与「关联任务卡片块」两种块类型，并提供清单项一键转任务的交互。
- 右侧上下文面板在文档视图中汇总本篇文档的全部关联任务卡片与反向链接，提供清晰的跨模块入口。
