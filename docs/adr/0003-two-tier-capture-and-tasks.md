# 碎片捕获与文档内任务采用双层分流机制

为兼顾高频无负担记录与结构化知识/行动管理，我们在捕获端与文档端均采用双层分流：(1) 右侧常驻 `Inbox` 同时接收待办 `Task` 与碎片小记 `Memo`，并配合左侧 `Memos` 工作台支持将 `Memo` 沉淀为 `Project`/`Book` 目录树中的正式 `Document` 或拆解为 `Task`；(2) 在 `Document` 正文中区分仅作用于文档内部的轻量 `Checklist`（`- [ ]`）与一键提升后跨 `Project` 及 `Today` 视图双向同步的一等公民 `Task`，防止临时文档自查项污染全局任务池。
